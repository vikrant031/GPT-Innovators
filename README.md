# HavenHomes Manual Testing Project

## About This Repository

This repository showcases the manual testing project for [**HavenHomes**](https://cyber-cyclist-039.vercel.app/), a company specializing in the construction of villas and resorts. The project focuses on ensuring the quality and functionality of HavenHomes' website through comprehensive manual testing.

The primary functionalities tested in this project include:
- User Authentication (Sign Up and Login)
- Navigation Bar
- Footer Section

The repository includes detailed documentation and findings from the manual testing process.

## About HavenHomes

HavenHomes offers a range of services, including architectural design, engineering, project management, and construction services. The company is committed to adhering to safety and environmental regulations while delivering projects on time, within budget, and to the satisfaction of its clients.

Website: [HavenHomes](https://cyber-cyclist-039.vercel.app/)

## Testing Process

The testing process involved:
1. Identifying critical features of the HavenHomes website.
2. Designing test cases to validate each feature.
3. Executing test cases and logging bugs, if any.
4. Retesting after resolving reported issues.
5. Documenting the entire testing process for transparency.
